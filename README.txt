LEDGER — ACCOUNTING SOFTWARE

GET STARTED IN VS CODE
1. Extract the ZIP file.
2. Open VS Code, select File > Open Folder, and choose accounting-software.
3. Open index.html in your browser. You can also use the VS Code Live Server extension.
4. Use Journal to record balanced entries, Accounts to manage accounts, and Reports to review the results.

EXAMPLE: Owner invests PHP 10,000 in cash
- Go to Journal; choose the date and enter "Owner investment".
- Line 1: Cash, debit 10000.
- Line 2: Owner’s Equity, credit 10000.
- Save entry.

EXAMPLE: Pay PHP 3,000 rent
- Rent Expense, debit 3000.
- Cash, credit 3000.

Amounts are entered in pesos with up to two decimal places. Opening balances must be entered as balanced journal entries. Reports calculate from your entries; the balance sheet includes accumulated income. Entries can be deleted and re-entered to correct mistakes.

Your information is saved in the browser's local storage on the same browser and device. Clearing browser data, changing browsers or devices, or changing where the app is served may make it unavailable. Use Download backup regularly, keep backups somewhere safe, and use Restore backup to recover them. Restoring replaces current data.

This is a starter accounting app, not a full professional or BIR-compliant accounting system. It has no user accounts, cloud sync, audit trail, invoicing, inventory quantities, payroll, tax calculations, or bank reconciliation. Consult an accountant for actual business reporting and tax compliance.
